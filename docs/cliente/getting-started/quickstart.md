# Quickstart

Caminho mais curto entre aceitar o convite e ver dado real na tela — sem
explicar todo conceito, só os cliques.

## 1. Entre no Cosmos

Aceite o convite recebido por e-mail, defina sua senha (ou entre via SSO, se
seu tenant usa) e faça login. Você cai direto no **Board Snapshot** — a visão
geral do seu tenant.

## 2. Confira seu papel e ART

No canto do Board Snapshot, veja qual papel você tem e em qual ART você está.
Se estiver errado ou vazio, peça pro Admin do tenant ajustar em
**Settings → Membros** antes de seguir — sem papel correto você não enxerga a
maioria das telas (ver [Permissões](../conceitos/permissoes.md)).

## 3. Olhe seu nível

- **Portfolio Manager ou dono de tema estratégico** → vá para **Portfolio**:
  veja o kanban de épicos e o ranking por WSJF.
- **RTE** → vá para **ART Board**: veja o program board do PI atual e as
  dependências entre times.
- **Product Owner ou Scrum Master** → vá para **Times → [seu time]**: veja o
  board de sprint com story, task, defeito e impedimento.
- **Liderança / quer visão consolidada** → vá para **Analytics**: veja
  previsibilidade de PI, flow metrics e value realization.

## 4. Próximo passo

Se seu ART ainda não tem PI planejado, siga
[Seu primeiro Program Increment](./primeiro-pi.md) para rodar o fluxo completo
de priorização até PI Planning.
