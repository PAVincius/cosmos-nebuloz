# Bem-vindo ao Cosmos

O **Cosmos** é a plataforma da Nebuloz para organizações que rodam **SAFe**
(Scaled Agile Framework). Ele reúne portfólio, ART, time e analytics sobre um
único banco de fatos — sem planilha paralela, sem exportar dado pra montar
apresentação, sem reconciliar três ferramentas pra saber se uma decisão
estratégica realmente entregou o que prometeu.

## O problema que o Cosmos resolve

SAFe organiza decisão em quatro altitudes — portfólio, ART, time e liderança —
e cada uma normalmente vive numa ferramenta diferente: Jira ou Linear para o
time, planilha para orçamento, Miro para PI Planning, dashboard manual para
relatório de liderança. Quando os dados não se conversam, ninguém responde com
segurança "o que essa aposta estratégica efetivamente entregou?".

O Cosmos junta as quatro altitudes no mesmo modelo de dados, então toda métrica
— previsibilidade de PI, valor realizado por tema estratégico, aging de um
board — deriva do mesmo fato gravado uma única vez.

## Para quem é

Se você é Portfolio Manager, RTE (Release Train Engineer), Product Owner,
Scrum Master ou lidera um ART ou portfólio rodando SAFe, o Cosmos é a
ferramenta onde seu trabalho do dia a dia — priorizar épico, planejar PI,
rodar sprint, olhar relatório — acontece sobre a mesma base de dados.
