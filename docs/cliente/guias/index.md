# Guias

Guias focados numa funcionalidade específica, para quando você já conhece os
[conceitos centrais](../conceitos/) e quer aprender a usar uma parte do
Cosmos a fundo.

- **[Portfólio: kanban de épicos e WSJF](./portfolio-kanban-wsjf.md)** —
  priorizar investimento com dado, não com opinião.
- **[PI Planning e confidence vote](./pi-planning.md)** — planejar um
  Program Increment e registrar compromisso do time.
- **[Board do time e métricas de fluxo](./board-do-time-e-metricas.md)** —
  trabalhar sprint a sprint e entender de onde vêm CFD, throughput e lead
  time.
- **[Integrações](./integracoes.md)** — conectar Linear, GitHub e webhooks de
  saída.
