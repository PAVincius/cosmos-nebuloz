# Configurações

Tudo que dá pra ajustar no seu tenant vive em **Settings**, organizado por
seção. A maioria exige papel de Admin.

| Seção | O que configura |
|---|---|
| **Workspace** | nome do tenant, módulos contratados |
| **Membros** | convidar pessoa, atribuir papel SAFe, definir ART |
| **Papéis customizados** | criar papel que adiciona permissão por cima do papel padrão — nunca restringe (ver [Permissões](../conceitos/permissoes.md)) |
| **SSO** | configurar login via provedor de identidade da sua empresa |
| **Segurança** | exigir 2FA, revisar sessões ativas |
| **Notificações** | quem recebe alerta de quê, e por qual canal |
| **Billing** | módulos ativos e cobrança — a parte financeira é operada pela Nebuloz, não editável aqui |
| **SAFe** | parâmetros do seu modelo SAFe: ARTs, times, altitudes ativas |
| **Auditoria** | trilha de eventos do tenant, incluindo tentativas de acesso negadas |
| **Integrações** | Linear, GitHub, webhooks de saída, API keys — ver [Integrações](../guias/integracoes.md) |
