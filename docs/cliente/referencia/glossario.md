# Glossário

| Termo | Definição |
|---|---|
| **Tenant** | Sua organização dentro do Cosmos; unidade de isolamento de todo dado. |
| **Módulo** | Produto contratado dentro do tenant: Cosmos, Charter, entre outros. |
| **Altitude** | Nível de decisão do SAFe: portfólio, ART, time ou liderança/analytics. |
| **Épico** | Aposta de negócio na altitude de portfólio; quebra em features. |
| **Feature** | Fatia de um épico distribuída para um time de um ART; quebra em stories. |
| **Story** | Unidade de trabalho do time; quebra em tasks. |
| **Task** | Menor unidade de trabalho, executada dentro de uma story. |
| **ART (Agile Release Train)** | Trem de times que planeja e entrega junto a cada Program Increment. |
| **Team** | Time dentro de um ART; sempre pertence a exatamente um ART. |
| **PI (Program Increment)** | Ciclo de planejamento do ART, com objetivos por time. |
| **PI Objective** | Compromisso de um time para o PI, com valor de negócio planejado. |
| **Confidence vote** | Voto de confiança do time no compromisso assumido no PI Planning. |
| **WSJF (Weighted Shortest Job First)** | Método de priorização de épico por Business Value, Time Criticality, Risk Reduction e Cost of Delay. |
| **Tema estratégico** | Unidade de investimento do portfólio, com lean budget e valor realizado. |
| **Lean budget** | Orçamento ligado a um tema estratégico e ao custo real incorrido. |
| **Value realization** | Comparação entre valor planejado e valor realizado por tema estratégico. |
| **Papel efetivo** | Papel SAFe resolvido para o usuário, podendo variar por ART. |
| **Papel customizado** | Papel que adiciona permissão além da matriz padrão — nunca restringe. |
| **Flow metrics (métricas de fluxo)** | CFD, throughput, aging WIP, lead time e DORA, derivados das transições de estado do board. |
| **Large Solution** | Altitude acima de ART, para coordenar múltiplos ARTs, capabilities e dependências entre eles. |
