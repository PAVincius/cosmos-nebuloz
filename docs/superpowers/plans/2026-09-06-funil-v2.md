# Funil v2 — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Levar `/funil` ao design do Big Bang: quatro estágios com peso e teto configuráveis (registro append-only), porta de entrada, canal com CAC, ACV estimado, board com arrastar-e-soltar, perda tipada, painel do estágio com métricas de 90 dias.

**Architecture:** `Lead` ganha colunas (estágio `PROPOSAL`, `estagioDesde`, `entrada`, `canalId`, `acvEstimadoCentavos`, `perdidoNoEstagio`, `notaPerda`); três tabelas novas no tenant `system` (`EstagioDoFunil`, `MudancaDeEstagio`, `CanalDeLead`) mais `HistoricoDeEstagio` por lead. Regras puras em `lib/comercial/funil.ts`; actions `leads.ts` (refeita) e `funil-config.ts`; UI em `app/(staff)/funil/` com board (DnD nativo), tabela, barras, e três diálogos (`Dialog` do `@repo/design-system`). Estados ganho/perdido derivados da proposta e de `perdidoEm`, nunca gravados como estágio.

**Tech Stack:** Next.js 16, Prisma 7, Vitest 4 (jsdom por arquivo), zod 4, kit Cosmos + `components/ui/dialog`, Biome.

**Spec:** [`docs/superpowers/specs/2026-09-06-funil-v2-design.md`](../specs/2026-09-06-funil-v2-design.md). Design de referência (cópia local para leitura): `.superpowers/sdd/2026-09-06-funil-v2/design/backoffice-funnel.jsx` e `backoffice-funnel-stage.jsx`.

## Global Constraints

- Tenant `system` em toda query; `requirePlatformStaff` → `assertCanWrite` → `safeAction` → zod → `logPlatformAudit` → `revalidatePath("/funil")`; `"use server"` só exporta async e types.
- Estágios abertos: `LEAD`, `DISCOVERY`, `EVALUATION`; `PROPOSAL` só por `converterEmProposta`. Ganho = `proposta.status === "ACEITA"`; perdido = `perdidoEm` ou `proposta.status === "RECUSADA"`; nunca gravados como estágio.
- Lead convertido ou perdido não move, não converte e não perde de novo (`buscarLeadAberto` continua a regra).
- Centavos `Int`; percentuais `Int`; `motivoPerda` ∈ `PRECO|TIMING|SEM_SPONSOR|CONCORRENTE|SEM_FIT|OUTRO`; `notaPerda ≥ 12`; motivo de mudança de estágio `≥ 20`.
- CAC por canal nulo = não medido: não soma, mostra "—". Sem números do design como dado (são fixture).
- Sem toast, sem lib de DnD, sem "Simular capacidade".
- Comandos: `cd apps/backoffice && npx vitest run __tests__/<arquivo>`; `npx tsc --noEmit --emitDeclarationOnly false`; Biome só nos próprios arquivos (`../../node_modules/.bin/biome check --write`); nunca `pnpm fix`/`pnpm check` na raiz; stage só arquivos próprios; `/usr/bin/grep`, `/usr/bin/git`; commits em português sem `Co-Authored-By`; banco local `cosmos_dev` (5434), nunca Supabase.

### Task 2: Regras puras — `lib/comercial/funil.ts`

**Interfaces (Produces):**
- `ESTAGIOS = ["LEAD","DISCOVERY","EVALUATION","PROPOSAL"] as const`, `type Estagio`, `ABERTOS = ["LEAD","DISCOVERY","EVALUATION"]`.
- `INFO_ESTAGIO: Record<Estagio, { rotulo; curto; descricao; tom: Tone }>` (do design: Lead/Descoberta/Avaliação/Proposta; tons neutral→blue, blue, accent, amber).
- `MOTIVOS_PERDA = { PRECO: "Preço", TIMING: "Timing / orçamento adiado", SEM_SPONSOR: "Sem sponsor executivo", CONCORRENTE: "Concorrente ou solução interna", SEM_FIT: "Sem fit com o método", OUTRO: "Outro" }`, `type MotivoPerda`.
- `PORTAS: Record<ProductModule, { degrau: "01".."05"; rotulo; dica }>` (MERIDIAN 01 Assessment, SCAFFOLD 02 Trilhas, SIGNAL 03 Medição, CHARTER 04 Governança, COSMOS 05 Operação).
- `type ConfigEstagio = { codigo: Estagio; pesoPercent: number; tetoDias: number; criterios: string[] }`.
- `type LeadFunil = { id; estagio: string; estagioDesde: string; situacao: "ATIVO"|"GANHO"|"PERDIDO"; acvEstimadoCentavos: number|null; proposta: { acvCentavos: number; status: string } | null; entrada: string|null; canalSlug: string|null; perdidoNoEstagio: string|null }`.
- `situacaoDe(perdidoEm: string|null, propostaStatus: string|null): "ATIVO"|"GANHO"|"PERDIDO"`.
- `diasNoEstagio(estagioDesde: string, hoje: Date): number` (dias inteiros, UTC).
- `estagnado(l: LeadFunil, cfg: ConfigEstagio[], hoje): boolean`.
- `valorDoLead(l): number`.
- `pipelinePonderado(leads, cfg): number`.
- `taxaLeadParaProposta(leads): { alcancaram: number; total: number; percent: number }` — alcançaram = estágio PROPOSAL, ou ganho, ou perdido com `perdidoNoEstagio === "PROPOSAL"`.
- `cacSobreAcvGanho(leads, canais: { slug; cacMedioCentavos: number|null }[]): { cacCentavos: number; acvGanhoCentavos: number; percent: number|null }`.
- `type Transicao = { leadId; de: string|null; para: string; em: string }`; `metricasDoEstagio(historico: Transicao[], estagio: Estagio, hoje: Date, janelaDias = 90): { entraram; avancaram; perdidos; permanenciaMediaDias: number|null }` — entraram = transições `para === estagio` na janela; avançaram = das que entraram, leads cuja transição seguinte é o próximo estágio (ou PROPOSAL/GANHO); perdidos = transição seguinte `PERDIDO`; permanência = média de dias entre entrada e transição seguinte (só as que saíram).
- `proximoEstagio(e: Estagio): Estagio | null`; `podeMover(l): boolean` (ativo e estágio ∈ ABERTOS); `podeConverter(l): boolean` (ativo e EVALUATION).

- [ ] Teste `__tests__/funil.test.ts` com casos: situação (ACEITA→GANHO, RECUSADA→PERDIDO, perdidoEm→PERDIDO); dias (fronteira UTC); estagnado com teto; valor (proposta vence estimativa); ponderado; taxa (perdido em PROPOSAL conta); CAC/ACV (canal sem medição não soma; sem ganho → percent nulo); métricas com histórico sintético de 3 leads (um avançou em 5 d, um perdido, um ainda no estágio → permanência = 5, avançaram 1, perdidos 1, entraram 3); fora da janela ignorado.

### Task 3: Actions

**Interfaces (Produces):**

- `criarLead({ nome, contatoNome?, contatoEmail?, entrada: ProductModule, canalSlug, acvEstimadoCentavos?, proximaAcao, proximaAcaoEm })` — canal precisa existir e estar ativo; grava `HistoricoDeEstagio(null→LEAD)` na mesma transação.
- `moverEstagio({ id, estagio ∈ ABERTOS })` — recusa `PROPOSAL`; `estagioDesde = now`; histórico `de→para`; mesmo estágio = no-op recusado.

- `converterEmProposta({ id })` — exige `estagio === "EVALUATION"`; transação cria proposta, seta `propostaId`, `estagio = "PROPOSAL"`, `estagioDesde = now`, histórico `EVALUATION → PROPOSAL`.
- `funil-config.ts`: `lerEstagio({ codigo })` → `{ config; mudancas: { id; campo; de; para; motivo; autorNome; criadoEm }[] }`; `atualizarEstagio({ codigo, pesoPercent?, tetoDias?, criterios?, motivo })` — `motivo ≥ 20`; recusa quando nada mudou; uma `MudancaDeEstagio` por campo (`campo` PESO/TETO/CRITERIOS; `de`/`para` "60%", "14 d", "3 itens"); transação; `atualizarCanal({ slug, cacMedioCentavos: number|null })`.
