# COSMOS UX Swarm — DCU Reports

Reports generated by the multi-persona UX validation swarm.

## Running the Swarm

```bash
# Full run (starts dev server automatically if not running)
cd apps/app
pnpm swarm

# Full run against existing dev server
PLAYWRIGHT_BASE_URL=http://localhost:3000 pnpm swarm

# Regenerate report from last run (no tests)
pnpm swarm:report

# Run with authenticated flows (requires real DB + seeded user)
AUTH_TEST=true E2E_EMAIL=test@cosmos.local E2E_PASSWORD=password123 pnpm swarm
```

## Architecture

```
e2e/
  swarm/
    types.ts          ← UxFinding, PersonaReport, SwarmReport types
    state.ts          ← per-persona findings files (whiteboard)
    reporter.ts       ← aggregation + markdown report generator
    global-setup.ts   ← clears state before each run
  personas/
    lpm.spec.ts       ← Lean Portfolio Manager flows
    rte.spec.ts       ← Release Train Engineer flows
    po.spec.ts        ← Product Owner flows
    sm.spec.ts        ← Scrum Master flows
    devops.spec.ts    ← DevOps Engineer flows
scripts/
  ux-swarm.ts         ← orchestrator (runs playwright + generates report)
playwright.swarm.config.ts ← 5 parallel workers, 1 per persona
```

## Inter-Agent Communication

Each persona writes findings to `e2e/fixtures/swarm/findings-{persona}.json`.
The orchestrator reads all files, detects cross-persona issues (same route + category
found by 2+ personas), and elevates their priority.

## DCU Score

`100 - (total_penalty / max_penalty) * 100`

Penalty weights: critical=20, high=10, medium=4, low=1, info=0

## Finding Categories

| Category | Description |
|----------|-------------|
| `route-missing` | PRD specifies a route that doesn't exist |
| `ui-error` | JS crash or component error |
| `design-violation` | Diverges from DESIGN.md tokens |
| `flow-blocked` | User cannot complete their primary task |
| `ux-friction` | Task possible but slow/confusing |
| `api-error` | Endpoint returns unexpected status |
| `accessibility` | Missing ARIA, contrast, focus |
| `performance` | Page load > 3s, action > 1s |
| `compliant` | Everything correct — positive finding |
