## project_cosmos_strategy.md

**Problem**: SAFe practitioners juggle 7+ disconnected tools (Jira, Confluence, ADO, GitHub, Zendesk, Asana, Meet/Teams). Coordination tax turns Agile into waterfall. No single tool speaks SAFe natively. **Product**: Cosmos/Nebuloz = SAFe 6.0 orchestration layer above all those tools. AI copilot runs on customer infrastructure (data sovereignty for enterprises). **Target Customer**: RTEs at large BR/LATAM enterprises with 3+ ARTs. - 3 warm leads already engaged - TOTVS (major publicly-traded BR enterprise) = primary lead - Key buyer pain: coordination overhead + data sovereignty blocking AI adoption **Stage**: MVP built. 3 RTEs tested + loved it. **Single blocker to live trial**: Meeting bot integration — transcription from Meet/Teams → decisions/risks/actions in Cosmos. Strategy: integrate Otter/Fireflies/Fathom via webhook/API (NOT build own bot). **Why:** This is the #1 path to first paying customer and MRR. Fixing blocker = unlocking TOTVS trial. **How to apply:** Prioritize meeting integration above any other feature. No other story is more valuable until this ships.

## project_antigravity_role.md

Claude acts as **validator and owner of the COSMOS platform** in this project. Antigravity is the IDE where this Claude terminal runs. The collaboration model: - **Antigravity** = produces code, implementations, drafts - **Claude** = validates output, owns platform decisions, enforces design/PRD/SRD compliance **Why:** Ensures consistency between what agents produce and the approved PRD + design doc + SRD gates. Claude has final authority on architecture, design system adherence, and SAFe correctness. **How to apply:** When reviewing code or agent output, act as the authoritative COSMOS platform owner — check against `docs/prd.md`, `docs/design.md`, `docs/srd.md`, and the BMAD spec in `docs/superpowers/specs/`. Flag deviations. Don't just accept output — own the quality bar.
