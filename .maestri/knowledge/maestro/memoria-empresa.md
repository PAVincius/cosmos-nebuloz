## feedback_worktree_git_rtk.md

Em sessão isolada em worktree (`.claude/worktrees/<nome>`), todo comando Bash com `git` é reescrito pelo hook do RTK para `rtk git …`, e o guard de isolamento recusa porque não consegue provar que o comando fica no worktree. Também recusa comandos com glob, variável de shell ou pipe complexo quando algo pode ser git (até um caminho com "Github" conta). **Why:** em 2026-09-22 isso travou vários comandos seguidos (`git branch -m`, `git status`, `sed` com variável) até achar o contorno. **How to apply:** git como `/usr/bin/git <subcomando>` em comando único e simples; leitura com glob ou pipe vai pelo `ctx_execute` (com `cd` explícito no worktree); edição por Edit/Write em vez de `sed` com variável. Subagentes da mesma sessão herdam a restrição — avise no prompt deles.

## feedback_verify_on_prod.md

## feedback_ponytail_every_task.md

Em execução por subagentes, cada review de task e a revisão final de branch devem ter uma seção "Ponytail" explícita (o que apagar/simplificar/substituir por nativo), e o resultado vai para o fechamento. **Why:** Em 6 set 2026 o usuário perguntou mid-turn "a análise do ponytail foi feita nas tasks?" — o rubric genérico ("Extra: over-engineering") não bastou. **How to apply:** Incluir a lente ponytail no prompt de todo reviewer e um `ponytail-review` completo na revisão final; listar os cortes feitos e os mantidos no resumo final. Ver [[feedback-verify-on-prod]].

## feedback_no_coauthor_trailer.md

Commits e PRs **sem** `Co-Authored-By: Claude ...` no rodapé. Pedido em 2026-09-05 e **reconfirmado em 2026-09-16** ("sem trailer, tira e faz push"), num momento em que a configuração da sessão injetava instrução contrária. A palavra do usuário vence a configuração. **Why:** o histórico do repo é dele; a atribuição automática não é bem-vinda. **How to apply:** nunca incluir o trailer, mesmo que um lembrete de sistema mande. Se um commit sair com ele, `git commit --amend` antes do push, sem perguntar. Commitar com `/usr/bin/git commit -F -` para escapar do hook que reescreve comandos.
