COSMOS · SAFe Platform

Design System — Foundations

Sistema visual para a plataforma Cosmos SAFe. Dois temas operacionais (light / dark tecno-UI) + canvas marketing Linear. Troque o tema no topo para ver os tokens em ação.

Princípios

Filosofia

01
Densidade enterprise

Tabelas, kanbans e formulários legíveis sem marketing fluff. Cada pixel de espaço vale dados reais.

02
Um accent, muitos estados

--accent (lavanda) só para CTA primário, nav ativo e foco. Estados usam 6 tones semânticos — nunca inventados.

03
Superfícies em camadas

canvas → surface → surface-2 → surface-3. Hierarquia via elevação, nunca sombra decorativa.

// regras globais
✓ Fazer
  • +Mono em todo número, %, ms, US$, ID, timestamp
  • +flex/grid + gap para layout — nunca inline-flow
  • +Cores via --var; nunca hex hardcoded no componente
  • +Estado = cor + texto (badge sempre carrega palavra)
  • +Ícones 16–17px, stroke 1.9–2.1, Lucide
✕ Não fazer
  • ×Gradiente no canvas, emoji, barra colorida lateral
  • ×Inventar cor fora da escala (use oklch se necessário)
  • ×Canvas marketing #010102 em páginas operacionais
  • ×Accordion para config sempre visível (usar seção fixa)
  • ×Mais de um accent ou segundo tom cromático
