# Task: Create SRD

**Actor:** `analyst`
**Input:** `docs/prd.md`
**Output:** `docs/srd.md` (specifically the section for the current Epic)

## Instructions
1. Read the PRD and extract the high-level requirements for the current Epic.
2. Define clear, numbered functional and non-functional requirements.
3. Identify data entities required.
4. Identify necessary API routes (without technical implementation details).
5. Output the result into `docs/srd.md` under the Epic's heading.
