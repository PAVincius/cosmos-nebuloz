# Task: Create Story

**Actor:** `po`
**Input:** `docs/srd.md` (Epic section), `docs/architecture.md`
**Output:** `docs/stories/epic-NNN/story-NNN.md`

## Instructions
1. Take the requirements from the SRD for the current Epic.
2. Break them down into small, executable user stories.
3. Assign WSJF (Weighted Shortest Job First) scores to each.
4. Use the `story-tmpl.md` template.
5. Save stories to `docs/stories/epic-NNN/`.
